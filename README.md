# Hola, soy Benjamín ⚡

Desarrollador web en Valparaíso, Chile. Trabajo en la intersección entre ecosistemas WordPress heredados e infraestructura moderna de alto rendimiento.

## 📦 Repositorios

### [gsap-lab](https://github.com/bbp96/gsap-lab)
Seis demos autocontenidas de animación web con GSAP y ScrollTrigger. Cada una documenta la técnica **y su costo en rendimiento** — porque hacer que algo se mueva es lo fácil; que se mueva sin arrastrar la página en móviles es el trabajo real.

Incluye entrada 3D con perspectiva, parallax multicapa, loops desfasados, suspensión de animaciones fuera del viewport, y el recalculo de triggers tras imágenes diferidas.

**[Ver las demos en vivo →](https://bbp96.github.io/gsap-lab/)**
